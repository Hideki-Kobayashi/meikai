# 問い合わせ対応の改善方針を説明するスライド

別セッションで試用した依頼文です。すべて架空のデータです。

```text
$meikai を使って、社内会議で説明するスライド資料を作成してください。

文案だけでなく、実際に閲覧・編集できるスライドを作ってください。表紙と目次を含め、全体で説明が完結する6枚程度の資料にしてください。

読み手は、問い合わせ対応の責任者と担当者です。会議の目的は、これまでの取り組みと実績を共有し、今後の改善方針を決めることです。

以下は架空の事例です。

【実施したこと】
・FAQを公開した
・同時に問い合わせフォームを変更した
・実施から3か月が経過した

【月間実績の変化】
・問い合わせ件数：500件から350件
・対応時間の合計：100時間から95時間
・パスワード再設定と請求書のダウンロードに関する問い合わせが減った
・個別調査が必要な問い合わせは減っていない
・問い合わせの種類別の対応時間は、まだ把握していない

【検討したいこと】
・個別調査の手順を整理したい
・具体的な進め方は提案してよい
・担当者、実施期間、削減目標は未定

この材料をもとに、構成、タイトル、本文、見せ方を決めてください。
```

スキルなしで比較する場合は、冒頭の「$meikai を使って、」を除きます。モデル、設定、ほかのスキル、入力をそろえて比較してください。
