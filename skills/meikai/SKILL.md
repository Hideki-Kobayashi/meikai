# 伝える内容から文章を組み立てる

読み手が必要な文脈を推測せずに、何について何を伝えているかを理解できる文章を最初から生成する。題材、資料、メモ、会話で共有された意図を出発点にする。修正対象となる下書きがあることを前提にしない。

## 生成手順

次の順で判断し、依頼された成果物を作る。手順は作業のためのものであり、そのまま出力の見出しにしない。短い文章でも判断は行うが、構成案や採点表を毎回出す必要はない。

### 1. 目的と読者を把握する

依頼と共有済みの情報から、次を把握する。

- 誰に向けた文章か。その読者がすでに知っていることは何か。
- 読んだ後に何を理解し、判断し、または行動できればよいか。
- 掲載先、文体、長さ、依頼された成果物の範囲。

未指定の体裁は用途に合うものを選ぶ。読者や目的の解釈によって中心となる内容が大きく変わる場合は、必要な点だけ質問する。執筆前の定型質問票を必須にしない。

### 2. 中心となる内容と優先順位を決める

文字数やタイトルらしさを考える前に、伝える内容を具体的な一文で表す。これは短いキャッチコピーではなく、文章全体の軸となる作業用の文とする。説明文なら「何について何を説明するか」、告知なら「誰にどの変更を知らせるか」など、目的に応じて定める。

材料を「中心となる内容」「理解を支える根拠・説明」「条件・補足」に分ける。材料の登場順や印象の強さだけで優先順位を決めない。複数の論点が競合する場合は、目的への寄与で順位を付ける。数値化する場合も編集上の仮の評価として扱い、客観的な重要度に見せない。

対象、比較軸、因果関係、主張の確かさを材料から把握する。欠けた事実をもっともらしく創作しない。中心となる内容を決めるのに不可欠な情報がなければ質問し、補足にすぎない不明点は省くか不明であることを示す。

### 3. 情報の配置を決める

読み手が理解するのに必要な順序で、中心となる内容と説明を配置する。前提が必要なら、その前提を使う説明より先に置く。結論先行などの型は目的に合うときに使い、すべての文章を同じ構成にしない。

- タイトルは、文章全体で扱う中心的な内容を示す。
- 見出しは、その節で扱う内容を示す。
- 本文は、主張を支える説明、根拠、具体例、条件を受け持つ。
- 段落ごとに役割を決め、話題が移るところで区切る。

タイトルや見出しが依頼されていなければ、形式上必要な場合だけ付ける。補足を本文へ回す際も、省くと誤解につながる対象や条件はタイトル・見出しに残す。

### 4. 本文を書く

配置に沿って、読者が対象と関係を追える文章を書く。

- 「差」「変化」「価値」などの語を使うときは、何の差か、何がどう変わるかが、その箇所までの文脈で分かるようにする。抽象語そのものを禁止しない。
- 比較する場合は比較対象と比較軸を示す。対比は材料に実際の対立や違いがある場合に使う。
- 接続表現は、前後の内容が持つ因果・対比・補足などの関係に合わせる。印象を強めるために関係を作らない。
- 一文に異なる論点を詰め込みすぎない。短く分ける場合も、主語や指示対象が分からなくならないようにつなぐ。
- 中心となる内容に寄与しない前置き、同じ説明の繰り返し、根拠のない強調を足さない。
- 事実、推測、提案を区別し、資料が支える強さで述べる。読みやすさのために条件や留保を消して断定に変えない。

### 5. 必要なタイトル・見出しを付ける

本文で実際に伝える内容をもとに、重要な対象と主張が分かる表現を選ぶ。全文を一律に圧縮するのではなく、その範囲で優先度が高い内容を選ぶ。

細かな経緯や説明は本文に任せ、意味が保てる範囲で短くする。短いタイトルの句読点や「しつつある」などの表現は、意味と読みやすさへの寄与を見て使う。文字数の固定目標や禁止語リストにしない。

タイトルだけを読む人にも、何の話かが分かるようにする。本文や一枚のスライドで裏付けられない大きな結論を掲げない。疑問形にするだけで、根拠のない仮説を持ち込まない。

### 6. 出力前に確認する

生成した文章を、次の観点で一度確認し、問題のある箇所を直す。

- 中心となる内容が、依頼の目的と一致しているか。
- 読み手に共有していない情報を前提にしていないか。
- 対象、比較、指示語の意味が文脈から分かるか。
- タイトル・見出しと、それが指す本文の内容や主張の強さが一致しているか。
- 簡潔にする過程で必要な条件を落としたり、材料にない事実・因果関係を加えたりしていないか。

これらを満たしたら完成とする。語感の好みだけで候補の生成と修正を繰り返さない。

## 出力

通常は完成した文章を返す。依頼されていない構成案、重要度ランキング、自己採点、作業実況は付けない。複数案や説明を求められた場合にだけ、選択に役立つ違いや編集上の判断を簡潔に添える。

## 着想元と適用範囲

- [いる科氏の投稿](https://x.com/iru_cection/status/2121705510319825086)：タイトルを作る前に伝えたい内容と優先順位を整理すること、曖昧な一語に文脈を詰め込まないこと。
- [中嶋よしふみ氏の投稿](https://x.com/valuefp/status/2121735384728232421)：タイトルに重要なキーワードを残し、詳細な説明を本文へ配置すること。

両投稿のタイトルに関する議論を、文章の新規生成へ応用した手順である。文章全体への適用はこのスキルの設計判断であり、投稿者が提案した手順そのものではない。投稿中の題材に関する推測や文字数の例を、一般的な事実や必須ルールとして扱わない。通常の利用時に投稿を読み直す必要はない。
